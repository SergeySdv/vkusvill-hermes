# ВкусВилл × Hermes: проект CLI и скилла

Дата проверки документации: 5 октября 2026 года.

## Статус

Это **проект интерфейса и пакет для реализации**, а не готовая CLI. В пакет входят техническое задание, кандидат SKILL.md, справочник команд, сценарии, локальная схема запроса и набор приёмочных кейсов. Исполняемая команда `vv` ещё не реализована. Скилл нельзя считать рабочим до реализации и проверки CLI.

Проверены официальные страницы ВкусВилла, Hermes, MCP SDK и MCPorter. Прямой сетевой POST к MCP из исследовательской среды не прошёл из-за DNS/network error. Поэтому живые `tools/list`, входные/выходные схемы, OAuth и сборка ссылки на корзину НЕ протестированы. Ошибка среды не означает недоступность сервера ВкусВилла.

## Принятое направление

Hermes → один skill `vkusvill` → детерминированная CLI `vv` → официальный MCP ВкусВилла.

Для реализации предлагается Python + Typer + Pydantic + официальный MCP SDK + SQLite. Конкретные совместимые версии закрепить после smoke-теста в отдельном окружении CLI, не изменяя зависимости установки Hermes. MCPorter использовать только как вспомогательный инструмент discovery/прототипирования, не как обязательный второй runtime.

CLI не содержит LLM, промптов, самостоятельного планировщика или второго agent loop. Она получает факты, проверяет ограничения, считает и сохраняет состояние. Hermes выбирает сценарий и объясняет результат. Оплата и оформление заказа не входят в проект.

## Файлы

- `IMPLEMENTATION_BRIEF.md` — архитектура, этапы, контракты и критерии готовности.
- `skills/vkusvill/SKILL.md` — кандидат процедуры для Hermes.
- `skills/vkusvill/references/cli.md` — предлагаемый, пока не реализованный интерфейс CLI.
- `skills/vkusvill/references/workflows.md` — процедуры подбора.
- `contracts/request.schema.json` — наша локальная схема пожеланий, НЕ схема MCP.
- `examples/request.json` — синтетический пример запроса, без реальных товаров/цен.
- `evals/cases.json` — приёмочные кейсы, НЕ результаты прогона.
- `SOURCES.md` — проверенные первичные источники.

## Установка после реализации

Сначала установить и проверить `vv` именно в том окружении, где работает terminal Hermes, включая контейнер/удалённый хост. Затем поместить каталог `skills/vkusvill` в skills активного профиля Hermes. Для стандартного профиля это `~/.hermes/skills/vkusvill/`. Проверить `hermes skills list` и начать новую сессию.

Не перезаписывать уже существующий скилл или конфигурацию Hermes без просмотра diff. Не импортировать токены из внутренних файлов Hermes в CLI: у CLI собственный поддерживаемый credential store. Не хранить секреты внутри скилла или репозитория.
